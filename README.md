# Schießbuch Pistole

Web-App (PWA) für Schießergebnisse. Läuft auf GitHub Pages, Daten liegen in Supabase.

- iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
- Windows: Seite im Browser öffnen (Edge/Chrome können sie auch als App installieren).

Dateien: `schiessbuch.html` (App), `supa-db.js` (Datenzugriff), `config.js` (Supabase-Projekt), `sw.js` (Offline-Cache), `setup.sql` (Datenbank-Schema).
